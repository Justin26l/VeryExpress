v0.8.2
- Fixed `createdBy` staying NULL in every generated app — audit user fields had no identity context.
- Removed `DataIsolationContext.middleware`; `Authentication.middleware` now establishes identity context from verified access token.
- Renamed `DataIsolationContext` to `UserContext`.
- Added `UserContext.run()` storing full access token payload, with normalized `userId` getter (`vexUserId` claim, `_id` fallback).
- Removed `dataIsolation` condition that gated context mounting.
- Removed `dataIsolation` parameter from controller generator.
- Added fail-loud error on create when entity declares `onCreateUserId` and context carries no identity.
- Added generation-time rule R8 — rejects `onCreateUserId` when app enables no authentication.
- Enabled data isolation on every authenticating controller; ownership filter previously mounted only on entities declaring `dataIsolation`.
- Added unit tests for `UserContext` normalization, async scope and concurrent isolation.
- Added unit tests for generation-time rule R8.
